# 🏦 SpendSmart

**SpendSmart** est une application de gestion des finances personnelles développée avec **ASP.NET MVC 8**. Elle permet aux utilisateurs de suivre leurs dépenses et revenus en temps réel, avec une base de données en mémoire pour une gestion rapide et efficace des données.

## 🚀 Fonctionnalités

- 📊 **Suivi des finances** : Enregistrement des revenus et dépenses.
- 🏷️ **Catégorisation des transactions** : Organisation des dépenses par catégories.
- 🔍 **Analyse des dépenses** : Visualisation des tendances financières.
- 🛠 **Stockage en mémoire** : Utilisation d’une base de données en mémoire pour une exécution rapide.

## 🏗️ Technologies utilisées

- **ASP.NET MVC 8**
- **Entity Framework Core (In-Memory Database)**
- **C#**
- **HTML / CSS / JavaScript**
- **Bootstrap** (pour le design responsive)

## 📌 Installation et exécution

1. **Cloner le projet** :
   ```sh
   git clone https://github.com/OussamaNaya/SpendSmart-ASP.Net-MVC.git
   cd SpendSmart
   ```

2. **Exécuter l’application** :
   - Ouvrir le projet avec **Visual Studio 2022**
   - Lancer l’application avec **IIS Express**

3. **Accéder à l’application** :
   - Ouvrir un navigateur et aller sur `http://localhost:7271`
